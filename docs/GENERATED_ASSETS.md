# Original demo assets

All six portraits in `apps/web/public/demo/` were made with the built-in image-generation tool for fictional demo identities. They do not represent real archived members. No API key or separately configured paid application AI provider was used for this asset workflow.

Each portrait prompt requested a square premium editorial head-and-shoulders photograph, natural window daylight, a softly blurred warm limestone studio, realistic skin texture, centered framing with space for an avatar crop, and no text, logo, watermark or border. Each explicitly asked for an invented person rather than a real existing individual.

## Visual card-first iteration · 18 September 2026

Six deliberately different fictional business-card artworks are reproducibly rendered by `scripts/create-visual-demo-assets.mjs` into `apps/web/public/demo/cards/`. Maya, Noah, Aisha, Raka and Elias use 1200×750 landscape artwork; Sofia uses 750×1200 portrait artwork. These are authored demo designs, not scans of real customers. The same script renders illustrative portfolio UI covers for Maya, Sofia and Elias. Those illustrations are sample work, not live customer dashboards or application AI output.

Three portfolio photographs were created with the built-in image-generation tool, copied into `apps/web/public/demo/covers/`, and visually inspected. No application OpenAI API key was used. All are fictional illustrative assets, not evidence of actual clients, completed projects or product results:
