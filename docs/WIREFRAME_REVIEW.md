# Personal DUIT wireframes — 21 October 2026

Discussion prototype only. No app implementation or release changes.

The in-conversation clickable wireframes cover People, Add person, Scan card, Review scan, Enter contact, Existing contact, Saved/phone contact, Person/history, Share, WhatsApp message, My Card, Edit and recipient web view.

Proposed navigation is People / Share / My Card. Adding a contact is available from People. Optional meeting context is collapsed initially. Phone saving is an explicit per-person action, not an agreed two-way sync specification. Sample data and all camera, contact-saving and message actions are simulated locally; the prototype makes no API calls.

The owner has requested wireframes before building the app. These proposals are for discussion, not final scope approval. Current open choices remain contact-sync semantics, required capture fields, prominence of meeting context and compact versus visual contact browsing.

Validation: Chrome rendered preview inspected. Add-person navigation, manual required-field feedback and save-confirmation flow exercised. Mock is isolated from real app accounts, contacts and messages.
